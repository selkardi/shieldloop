# Evaluation report (1–2 pages)
1. **Test set:** size, how it was built (real / synthetic / reviewed), share of hard and unanswerable cases.
2. **Metrics:** definitions; values with 95 % confidence intervals.
3. **Baseline vs system:** table (prompt only, then each improvement).
4. **Error analysis:** failure types with counts and one example each.
5. **Cost and latency:** per answer, at expected volume.
6. **What we would do next.**
